# 12주차 인터랙티브반 공통 실습 파일

## 목적
연도 선택에 따라 실업률 수치·설명·그래프가 바뀌는 실습용 웹페이지를 확인하고 GitHub Pages로 배포한다.

## 파일 구조
- `index.html`: 페이지 구조
- `css/style.css`: 페이지 디자인 및 반응형 스타일
- `js/script.js`: 진입 효과 + 연도 선택 기능
- `images/year-a.svg`, `images/year-b.svg`: 가상 실업률 그래프 (실제 통계 아님)

## 동작
- 처음에는 연도 A의 4.2%, 설명, `images/year-a.svg` 그래프가 표시된다.
- 연도 B를 선택하면 3.6%, B 설명, `images/year-b.svg` 그래프로 함께 전환된다.
- 연도 A를 다시 선택하면 A의 내용으로 복원된다.
- 선택된 버튼만 활성화되며 스크롤 시 섹션이 등장하는 효과도 유지된다.
- 표시되는 수치는 모두 학습용 가상 데이터다.

## 검증
1. 처음에는 연도 A와 4.2%, A 설명, A 그래프 및 활성화된 A 버튼이 표시되는지 확인한다.
2. 연도 B를 클릭해 3.6%, B 제목·설명·그래프 및 활성화된 B 버튼을 확인한다.
3. 연도 A를 다시 클릭해 모든 A 내용과 버튼 상태가 복원되는지 확인한다.
4. 페이지의 다른 섹션과 스크롤 등장 효과가 유지되는지 확인한다.
5. 표시된 수치가 학습용 가상 데이터라고 안내되는지 확인한다.
6. GitHub Pages에 게시한 주소에서도 이미지·스타일·버튼이 제대로 표시되는지 확인한다.

## GitHub Pages 배포
1. VS Code에서 폴더를 열고 브라우저로 `index.html`을 실행한다.
2. GitHub 저장소를 만들어 이 폴더의 파일을 저장소 **루트**에 업로드한다.
3. 저장소 `Settings > Pages`에서 `Deploy from a branch`, `main`, `/(root)`를 선택한다.
4. 제공되는 Pages URL로 접속해 이미지·스타일·버튼이 제대로 표시되는지 확인한다.

> 그래프와 수치는 실습용 가상 데이터이며 실제 실업률 통계가 아니다.
