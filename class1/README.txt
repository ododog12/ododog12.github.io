문제: 1~3 웹 구조 / 4~9 HTML 관계 / 10~15 HTML 수정 / 16~30 CSS 선택자 / 31~39 CSS 속성·레이아웃.

선택형은 코드의 여는 태그를 눌러 선택합니다. 복수 정답은 여러 개를 클릭하세요.
